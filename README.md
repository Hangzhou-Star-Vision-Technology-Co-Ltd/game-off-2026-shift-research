# Game Off 2026 SHIFT 研究与策划初稿

本仓库研究 Game Off 2026 的 SHIFT 主题、历届高排名作品、当届评价方式与可实施选题。目标是为一个可完成、可理解、主题与规则一致的独立游戏提供选题依据，而不是给出“获奖公式”。

**研究日期：2026年11月2日。状态：策划研究，尚未制作游戏原型，尚未作出参赛或游戏源码公开决定。** 本仓库只公开原创研究与公开来源，不包含既有项目源码、凭据、私人资料或第三方资产。

## 当前推进方向：地中海短单航运（2026-11-03）

新增[地中海航运游戏系统策划](航运系统策划/README.md)：亲自接单驾船、靠港交货即时结算，从旧船成长为小船队；以运输改变供需和有利航路验证SHIFT。完整覆盖操作、订单、经济、升级、船队、UI、事件、MVP、测试、里程碑和来源。

熟练短航从接单确认到到账以20–30秒为待测目标，不设置强制催单倒计时。数值与制作范围为原型假设，尚未进行实机验证。本次仅公开策划，没有游戏代码、素材或正式赛事提交。

下面的候选排序和原《推荐方向策划初稿》保留为11月2日历史研究；当前航运方向的实施讨论以新目录为准。

## 先看结论：事实与设计建议

1. **SHIFT 应改变玩家的选择，而非只改变标题。** 我们的设计检验要求回答：转移什么、由谁触发、失去什么、为什么不能总选同一种状态。按 Shift 键、轮班题材或双世界美术都可以符合词义，但不自动构成好机制。
2. **Game Off 是参与者互评，不是已知专家评委按商业指标打分。** 官网列 Overall、Gameplay、Graphics、Audio、Innovation、Theme Interpretation。没有已核实的官方百分比权重；本届后台总榜配置不可见，不应自行伪造算法。
3. **历届不存在单项冠军配方。** 2024 Overall冠军 Trail of Secrets 的 Graphics为58名；2022冠军Theme为78名；2025 Ooqo的Gameplay和Graphics均第一，但Overall并列第7。主题、创新、视听都值得投入，但“某一项第一”不是综合第一的必要条件。
4. **完成度不是没有缺点，而是一个清楚的体验承诺得到兑现。** 小场景反复发现、一个动作做深、紧凑氛围叙事、规则构筑都出现过高排名案例。作品页还保留教学、兼容性或难度反馈，适合作为我们的验收清单，而非只看精选好评。
5. **本届仍在早期，不能拿少量页面判断竞争格局。** 已可见换挡、轮班和昼夜行为切换样本；这只能说明这些解释已有实践，不能证明其他方向空白。

## 11月2日历史候选方向

1. **移潮救援**：移动共享浮岛带，同时影响多艘自动航行的船。整行滑动已有直接先例，差异待证在同步救援冲突；目前局部情境还未求解，不能直接开工。
2. **失位供电**：移位出界会永久损失供给，各位置按时间消费电力。bit shift谜题已有作品，须验证跨轮资源取舍而非二进制换皮。
3. **交班留痕**：只能把有限结构化信息交给按明确规则工作的接班人。须验证信息压缩改变维修顺序，而不是固定便签排序题。

七案均提供近邻、现有与拟新增规则、因果链、最小范围、对照及失败标准。排序是研究判断，不是官方评分或获奖预测。首选仍有规则风险，优先进行纸面反证而非生成成套素材。

## 官方时间与公开边界

当前[官方赛事页](https://itch.io/jam/game-off-2026)公布提交截止为 **2026年12月1日21:37 UTC**，即 **北京时间12月2日05:37**；投票结束为2027年1月1日同一UTC时间。计划应提前完成，不依赖临界时刻提交。

官方要求游戏源码在GitHub公开，但允许自行选择许可证；公开可见与授权他人使用不是同一件事。研究仓库的公开不等于未来游戏源码或既有商业工程的公开授权。最终参赛作品、代码许可证、资产分发范围与AI披露须在制作和提交前另行确认。
