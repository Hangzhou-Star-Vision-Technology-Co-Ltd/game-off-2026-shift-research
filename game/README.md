# 蓝湾航运 · SHIFT 1.0

一款离线可玩的航运经营短游戏。亲自跑一单、停稳卸货、即时收款，再升级爱船、购入助手船。货物流动会改变真实库存、缺货程度和后续报价，这就是本作的 SHIFT。

## 开始试玩

下载并解压整个仓库，在本目录执行 `python3 scripts/restore-assets.py`（Windows也可使用 `py scripts/restore-assets.py`），然后用较新的 Chrome、Edge、Firefox 或 Safari 打开 `index.html`。保留还原后的 `assets/`。不需要第三方依赖、登录或联网。现成离线试玩包无需这一步。

本仓库保留可编辑HTML源码与全部本地素材。手机聊天应用的文件预览未必执行 JavaScript，请下载后用浏览器打开；如本机不支持打开本地HTML，可在电脑试玩。

开发时可在本目录运行 `python3 -m http.server 8080`，访问 `http://localhost:8080`。

## 操作与目标

- 接单后扬帆。W / ↑ 加速，A D / ← → 按船头方向转向，S / ↓ 减速。
- 可点击海面指定航向，再点「扬帆航行」持续行驶。手动掌舵会取消指定航向。没有避礁或泊港自动驾驶。
- 到目的港金色光圈内减速，停稳约1.8秒自动卸货、收款。
- 空格 / Tab 打开海图；Esc 暂停。也有完整触屏按钮。
- 接单时锁价，擦碰最多损失3金币完好奖励，不损失基础运费。
- 读单、海图、确认框、引导、结尾和后台都暂停世界。没有离线收益。
- 助手船每次运5格，约48秒完成一单后待命，不会连续自动接单。
- 港务信件是保底委托，不改变货物库存或产业周转。

终局目标：拥有旗舰与海鸥号两艘船；向四港实际送过货；历史上稳定两组不同的港口/物资缺口；助手至少完成一单。稳定需在交货引发生产/消费之后，库存由不足40回升到至少40。达成后可继续经营、回看结尾或确认重开，不发重复奖励。

本版按既有MVP允许的收缩，以两艘船结束，保留亲驾到调度的变化。没有第三艘船、战争、阵营、战斗、开放世界或在线账户。

## 存档

沿用v1经济存档。自动保存到当前浏览器、当前来源，文件位置或浏览器不同不保证共享进度。日志页支持导出JSON备份和验证后导入；导入覆盖前会确认，并保留上一次存档恢复副本。损坏存档会尝试保留恢复副本并显示警告。隐私模式或存储权限限制时请立即导出备份。

## 音画

运行版在 `assets/` 使用19张无损WebP，较大文件从 `asset-parts/` 原样还原。19张即梦PNG原图的SHA-256及运行图来源见 `素材来源.json`，PNG重复品未纳入本仓库。素材沿用v0.3，不声称进行了新一轮生成或重绘。代码实现界面、镜头、水面、帆部署、尾迹、轻柔的合成旋律和反馈音效。默认静音，点击顶部♪开启，在「怎么玩」调节音量。无外部字体、CDN、统计、广告或外部网络请求。

## 开发与测试（仅仓库源码）

离线试玩包只包含已还原的运行文件。以下脚本与测试在GitHub源码中提供，试玩不需要执行开发命令。

需要Node 18+，不需要第三方依赖：

```
npm test
python3 scripts/build.py
```

`npm test`运行原核37项、发布完整性/存档/终局检查与8条物理航线。`python3 scripts/build.py`打包轻量离线ZIP。此前实际Chromium浏览器验收及其覆盖边界见 `qa/TEST-REPORT.md`，本次推送没有将未复验的浏览器步骤当作新测试。

English: Take a job, sail with W/↑, steer A/D, brake with S/↓ inside the destination ring to deliver. Space/Tab opens the chart. Restore two shortages, deliver cargo to all four ports and grow a two-ship fleet. No deadlines.
